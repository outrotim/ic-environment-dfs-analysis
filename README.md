# IC–environment interaction and disability-free survival

Version 1.0.0 of the analysis code accompanying the manuscript:

> Environmental support is more strongly associated with disability-free survival when intrinsic capacity is preserved

This repository provides the complete 19-script analysis pipeline, aggregate
result tables, figure outputs, reporting documents, and regression tests. It is
intended for transparent re-analysis by registered users of the source cohorts.
It contains no individual participant data.

## Transparency and registration timing

This deposit is a **retrospective research archive, not a pre-registration**.
The statistical analysis plan is dated 11 March 2026 and was maintained locally
before the first substantive Cox model, but it was not posted publicly before
analysis. Deviations and analysis-stage decisions are described in
`docs/ANALYSIS_TIMELINE.md` and the statistical analysis plan.

## Data access

Individual participant data cannot be redistributed under the cohort data-use
agreements. Registered researchers can obtain the source files from HRS
(https://hrs.isr.umich.edu), ELSA (https://www.elsa-project.ac.uk), CHARLS
(https://charls.pku.edu.cn), SHARE (https://share-eric.eu), MHAS
(https://www.mhasweb.org), and KLoSA (https://survey.keis.or.kr). Harmonised
files are available through the Gateway to Global Aging Data
(https://g2aging.org). SHARE Waves 1–9 use persistent identifiers
`10.6103/SHARE.w1.900` through `10.6103/SHARE.w9.900`.

Set these environment variables before running the pipeline:

```bash
export STUDY17_PROJECT_DIR="$PWD"
export STUDY17_RAW_DATA_DIR="/path/to/harmonised/cohort/csvs"
export STUDY17_KLOSA_DTA="/path/to/H_KLoSA_e2.dta"
```

The five main CSV files must be named `hrs.csv`, `elsa.csv`, `charls.csv`,
`share.csv`, and `mhas.csv`. Run all steps with `Rscript 00_run_all.R`, or run
the numbered scripts individually. The full pipeline is computationally
intensive; `00_run_all.R --from=06 --to=19` resumes from prepared intermediate
files.

## Interpretation guardrails

The primary interaction is interpreted on the relative hazard scale. Additive
interaction was not detected, standardised absolute risk differences were
similar across IC strata, between-cohort heterogeneity was substantial, and
KLoSA was directionally consistent qualitative replication with a confidence
interval crossing 1. MSM and weighting analyses do not eliminate unmeasured
confounding.
