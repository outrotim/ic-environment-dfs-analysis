# OSF project metadata

**Title:** Intrinsic capacity–environment interaction and disability-free survival in older adults: harmonised analysis of five international cohorts

**Category:** Project

**License:** CC BY 4.0 for documentation; MIT for code

**Tags:** intrinsic capacity; environment; disability-free survival; healthy ageing; HRS; ELSA; CHARLS; SHARE; MHAS; KLoSA

**Description:** This project contains the analysis code, statistical analysis
plan, harmonisation documentation, aggregate results, and figures for a
harmonised longitudinal analysis of five international ageing cohorts with
reduced-indicator qualitative replication in KLoSA. This is a **retrospective
research archive, not a pre-registration**. The SAP was maintained locally
before the first substantive outcome model but was not posted publicly before
analysis. No individual participant data are included or redistributed.

**Repository:** https://github.com/outrotim/ic-environment-dfs-analysis
